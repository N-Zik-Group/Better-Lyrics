  <h1>Better-Lyrics</h1>

    word-by-word synchronization support, used in the
    <a href="https://github.com/N-Zik-Group/N-Zik">N-Zik</a> project.
  </p>
  <p>
    <strong>Note:</strong> This project is a fork of the Better Lyrics implementation
    originally created by <a href="https://github.com/MetrolistGroup/Metrolist">MetroList</a>.
  </p>

# 🎧 Features

- Parses TTML (Timed Text Markup Language) lyrics
- Built in Kotlin

# 📜 Integration

This library is designed to be added as a submodule in Android projects.

```groovy
// settings.gradle.kts
include(":betterlyrics")

// build.gradle.kts (app)
implementation(projects.betterlyrics)
```
